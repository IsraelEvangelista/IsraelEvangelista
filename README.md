## Hi there 😄 

I'm **Israel Evangelista**, a data analyst and science enthusiast with over a decade of experience at COGERH since 2012. I've evolved through various roles in grant analysis and information management, specializing in database innovation and user relationship analytics.

### 💼 Professional Background

My expertise spans across multiple domains:
- **Data Analysis & Visualization**: Advanced proficiency in Excel, Power BI, and Looker Studio for descriptive and diagnostic analysis
- **Database Management**: Strong skills in MySQL and PostgreSQL querying, with solid experience in relational database modeling
- **Programming**: Python for data analysis, leveraging Google Colab and Jupyter notebooks
- **Low-Code Development**: Intermediate experience with AppSheets for rapid app development

Since early 2022, I've been pursuing formal Data Science studies, which has significantly enhanced my capabilities in constructing analytical scripts and neural network models for predictive and prescriptive analyses. I'm passionate about continuous learning and deepening my expertise in data-driven decision making.
